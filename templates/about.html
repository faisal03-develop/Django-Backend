About

Learn what this backend project is for and how it is organized.

What is this project?

This is a Django backend server that serves HTML pages and can be extended with REST APIs, authentication, and database models as your needs evolve.

The site you are viewing is built with Django templates, static CSS, and simple view functions—no extra frameworks required.

Tech stack

Framework: Django 6

Database: SQLite (default, suitable for development)

Frontend: Server-rendered HTML with a shared base layout

Next steps

You can add new apps with python manage.py startapp, wire up API endpoints, or connect a frontend framework. Use the Contact page if you want to reach out with questions or feedback.
